# QuickKV v2.0.0 第七轮收尾

| 编号 | 实现及验证 |
| --- | --- |
| R7-01 | 保留前后缀的即时搜索与配置引用入口。 |
| R7-02 | 在 Qt 额外选区中提高虚线的深浅主题对比度，沿用 Qt 依据字体绘制的线宽，不增加背景或改变行高。 |
| R7-03 | 三栏方案增加源内容和多方案提示。本体及归属使用不同字号，长内容保留悬浮提示。 |
| R7-04 | 归组标题标明角色，继续使用可搜索换行词片、已有归属、同名处理和新组命名。 |
| R7-05 | 最终确认使用横向前缀、主词、后缀三列，词汇及处理各一行，保留实际变更计数和共享规则说明。 |
| R7-06 | 当前组和默认展示共用组内新增入口，同组切换保留修饰值。 |
| R7-07 | 模块主词范围、前后缀引用和全局定义分别操作。主词配置优先定位真实绑定，可单独查看已移出模块的绑定组。全局定义管理仍使用既有删除确认和备份。 |
| R7-08 | 配置入口统一称「引用已有词组」，使用现有主题主操作样式。 |
| R7-09 | 候选支持外部点击关闭、Esc、悬浮延时与候选和浮窗之间的短距离桥接。点击浮窗后停止悬浮关闭。真实输入法及真实鼠标跨区仍待验。 |
| R7-10 | 修饰新词使用一次归组确认，随后通过原事务写入组、专用词库、引用及草稿。已有词或组的其他确认路径按原规则。 |
| R7-11 | 片段按勾选顺序批量插入，筛选保留选择。批量插入只进行一次编辑提交，生成独立的节点及词元身份。复制、移动、删除与排序先提交待保存内容，移动和删除使用保护快照。搜索或跨模块浏览时禁用目录排序。 |
| R7-12 | 正文右键先显示上下文适用的组合输入操作，再显示通用编辑和大纲操作。 |
| R7-13 | 延续 QuickKV 深浅主题、字体与独立浮窗。保留 Windows Qt 隐藏窗口渲染作为可读性和布局证据。 |

版本维持 v2.0.0，数据库及备份格式保持兼容。旧版单实例激活及连续联想候选定时的历史偶发现象继续追踪。真实输入法、VS Code 选区采集、外部回写降级和多屏 DPI 仍需实机验收。参考材料和本轮渲染放在 Git 忽略目录。

## 交付证据

- 全量 147 项通过。Windows Qt 隐藏窗口 21 项通过。第七轮新增覆盖按勾选顺序插入与整批撤销、主词当前组新增与模块配置隔离、候选外部关闭、新修饰词单次归组事务及横向确认取消。
- 用 Windows 原生 Qt 隐藏窗口走通候选选择、角色归组、横向确认及事务写入，核对主词配置、全局词组管理和片段勾选渲染。浅／深主题分别渲染候选下划线，悬浮桥接使用程序化悬浮信号和指针位置验证。
- 使用第六轮虚构数据库、专用 Markdown 词库和归档备份的独立副本验证恢复。原有片段、草稿及结构可读取，生成有效恢复前保护快照。
- 两套最终目录的 Windows 文件版本和产品版本为 2.0.0。体验目录提供已知与歧义候选、修饰引用和多份初始片段。空白目录无用户词库和数据库。
