# 第九轮输出机制统一

本地验收版本继续使用 v2.0.1。

| 范围 | 实际行为 |
| --- | --- |
| R9-01 | 移除主窗口预览按钮与预览窗口生命周期。保留片段及词条自己的预览能力。 |
| R9-02 | 两个编辑器均以「复制」输出全文。确认写入剪贴板后显示「复制成功」，提示在底部空位显示，正文几何保持不变。 |
| R9-03 | 复用 Windows 前台、焦点及光标事件。排除自身、常见系统界面、不可编辑控件及无输入证据的位置。落字准备冻结目标及输出，发送前校验进程、窗口、焦点、光标和剪贴板。发送后反馈「已发送到」。 |
| R9-04 | 普通模块、回载模块和连续联想共享全局转写。输出只准备一次。降级复制沿用已准备的文本，转写异常取消输出。 |
| R9-05 | 移除手动检查菜单。启动、文件监听、相关写入及备份、恢复使用现有事务恢复逻辑。未能安全完成时留存文件与事务材料。 |
| R9-06 | 自动、手动备份包含模块正文。自动检查和最短间隔为 15 分钟，正文变化进入版本判断，验证新备份后才轮换有效旧备份。兼容历史备份及旧设置。 |
| R9-07 | 沿用模块自动保存。拒写时保留编辑态并重试。用「模块正文」区分组合输入与连续联想的临时草稿。 |
| R9-08 | 目标按钮固定布局宽度，长名称省略，悬浮显示全称。输出反馈不占用正文布局。历史单实例和候选定时偶发记录仍保留。 |

## 安全边界

回载来源独立于当前落字目标。原 v2.0.1 本地验收版的外部回载只能读取及复制回原应用。本轮有原生编辑控件证据且选区折叠时可以发送普通落字。无法可靠核验选区或文档身份时，降级复制。未建立对旧外部选区的自动替换保证。

Windows 独立 EDIT 控件验证识别成功。异步试验中前台切走，最终守卫拦截，控件正文保持为空。实际第三方应用接收、同一应用的自绘编辑位置及真实输入法继续人工验收。

## 验证结果

- 全量离屏自动化 158 项通过。新增验证动态目标双模式同步、同窗口光标改变阻断发送、旧设置下仅正文变化触发完整备份，以及输出提示显示时编辑器布局保持。
- Windows 原生 Qt 隐藏窗口组合输入专项执行 54 项，53 项通过。需隔离剪贴板的 1 项已在离屏全量运行。
- 原生 Win32 EDIT 检测通过。真实前台变化阻断了隔离发送试验，原编辑控件未收到输入。实际目标接收仍须人工验收。
- PyInstaller 构建成功，文件产品版本 2.0.1。界面渲染、模拟体验版及空白测试版均置于独立 R9 目录。
