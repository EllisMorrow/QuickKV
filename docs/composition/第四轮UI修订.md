## 数据与兼容性

- 未归组词只记专用词库。当用户需要规则时创建或明确选用词组，其他模块和历史组合词保留自身设置及字面。
- 对未知结构，只扫描候选时没有词库写入。新词、角色关联与稳定组合词草稿共用一个事务记录。确认失败时保留正文，冲突仍按现有恢复机制处理。
- 外部选区采集与回写是独立能力。采集不会隐式授权覆盖原选区。保留现有回写守卫及复制降级。
- 新体验数据包含四级分类、独立模块、同名冲突、未归组主词及混合回载。仅使用虚构数据。
