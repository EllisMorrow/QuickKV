# QuickKV 组合输入第二轮 UI 修订

| 项目 | 处理及验证边界 |
| --- | --- |
| Q19 | 观察提示跟随视口更新和尺寸变化重新定位。自动验证三种宽度下右侧间距 |
| Q20 | 根据冻结的词元结构定位前缀、主词和后缀。分隔符或无法确认的历史字面用三向入口。测试通过正文点击三处 |
| Q21 | 普通面板统一缩窄，紧凑入口更小，双栏和配置按需扩宽。固定左侧角色点击区，主词配置优先定位绑定组。默认星期格式显示中文，历史时间仍按快照保存 |
| Q22 | 修复子控件 resize cursor 覆盖未被撤销的路径，退出边缘或窗口失焦时恢复原光标。自动覆盖边缘与离开事件。用户报告的完整偶发序列待实机确认 |
| Q23 | 空查询列出可用组词片，下拉支持移除模块内组入口。清空最后一个入口保留显式空范围，旧空范围仍表示全部 |
| Q24 | 复用现有词库匹配与排序，为结构化候选复用同一匹配器及目录缓存。结果标明组和来源，必要时显示全文预览。普通词条预览沿用匹配高亮，结构化候选暂无逐字高亮 |
| Q25 | 同词按组归并，多组要求选择。复杂条目按原词条插入。短词未关联时可临时用或主动关联。程序化验证歧义与多行原文 |
| Q26 | 标题模式按钮的可点击范围避开边缘缩放拦截；切换时关闭相关浮窗并保留各自草稿 |
| Q27 | 词元按钮移至同级左侧 |
| Q28 | Markdown 使用独立只读工具窗，同步输出并提供源码，不加载外部资源。验证打开后正文几何与后续文本同步 |
| Q29 | 模块和模板移除下拉箭头，保留回载菜单标识 |
| Q30 | 模块词组配置使用搜索和可换行的多选词片，过滤保留选中项。保留轻量附属窗口 |
| Q31 | 模板中心支持空白新建、分支新建、原地编辑和明确提交。原有清空策略及结构化草稿保留 |
| Q32 | 模板中心改为非模态，插入使用当前有效正文光标；关闭或切换会隐藏中心，在本次运行内保留未保存编辑。自动验证主窗继续接收输入及重新定位后插入 |

## 原生渲染核对

使用虚构数据及 Windows Qt 隐藏窗口渲染了普通词片、主词配置、独立 Markdown 预览及非模态模板中心。普通面板与配置页采用不同宽度。模板预览使用保留结构的编辑控件，Markdown 工具窗使用渲染和源码两种视图。多来源结果使用单个候选区和按需全文预览。首轮测试中的真实 IME、跨屏 DPI、鼠标手感和长期观察仍适用。

原参考资料及本轮渲染均保留在本地忽略目录。两种测试包使用独立数据目录。
