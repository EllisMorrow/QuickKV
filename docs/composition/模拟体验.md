# QuickKV 组合输入模拟体验

如需完整演示数据，先用下方命令从发布前验收包生成独立体验目录，再启动其中的 QuickKV.exe 并进入「组合输入」。首次启动遵循正常声明确认流程。体验包与空白测试包各自使用自己的便携数据目录。

- 项目管理、阅读学习、日常事务各有已建立组合词的主草稿。点击「行动」后的组合词，试选前后缀、替换主词、撤销，以及到「配置」查看共享前缀和分类。项目行动的前缀有七组。
- 每个模块有两份示例。第二份通过「回载 → 打开已保存的回载草稿」选择对应标题。另有校验示例用于浏览确定、未知和歧义候选，以及图片路径和行内代码保护。
- 从「片段」插入当前模块的两个分支片段。点击分析节点旁的观察提示，查看四种状态和嵌套分析。
- 「更多 → 备份与恢复」内已有一份体验基线。体验目录的「异常示例」只用于试验拒绝导入。
- 在已保存的回载草稿中打开第一行含两个「晨检+校准」的示例。忽略第一个，观察后面的候选仍然可用，再划选第一个并用「识别选区」恢复提示。点击候选查看单加号的两种解释。
- 将原型或复核行动组中的主词替换到已有项目行动组合词，检查前后缀范围变化。到模块中心勾选多项，试批量移动。片段中心中新建并编辑名称及正文，切换一项或关闭后再次打开，核对自动保存状态。
- 切换到项目管理，勾选两份片段再插入正文，按列表中显示的勾选序号检查顺序，使用一次撤销移除整批。用组合词面板的「配置」查看当前角色引用，用「词组」打开全局管理。
- 空白模块可用于自行从零体验。

## 安全重置和重新生成

可以用体验包管理面板恢复「体验基线」。正常恢复会保护当前草稿，如果需要完全干净的体验，请从一份尚未运行的空白本地测试包生成新目录。生成器要求输出目录不存在，已有体验目录可以留作记录。

```powershell
.\venv\Scripts\python.exe tools/create_composition_demo.py '.\dist\QuickKV-v2.0.0-发布前验收' '.\dist\QuickKV-v2.0.0-体验副本'
```
