## 对照复现

- 第四轮旧包中的识别代码对无字段标签的虚构项目符号行识别出 0 个候选。本轮识别出 1 个，并通过隔离剪贴板的实际菜单、正文点击和确认入口完成建立。
- 使用第四轮包提取的原编辑通知处理函数运行 Qt 原生替换回归，未变的组合词结构被移除。第五轮在相同编辑控件和数据下保留同一 ID。
- 旧检索用模块展示组构建结果和原词条归属，显式窄范围外的同词或词组无法进入结果。本轮全局检索和收藏回归验证仅在确认时写入相应的模块或共享规则。
- 旧字体设置只更新搜索主窗局部字体，默认 Qt 对话框及局部 QSS 仍使用其他字体。新入口更新应用默认字体，Windows Qt 验证已打开和新开的控件采用配置的字体与字号。
- 全量 138 项通过，保留第四轮原有 131 项；Windows Qt 隐藏窗 12 项通过。另验证原生窗口中的字体更新和空白模块新建／取消，并检查字体、全局组、修饰词搜索和未知候选渲染。
- VS Code 截取和外部自动回写仍是实机项目。真实中文输入法、跨屏高 DPI、屏幕主题混搭及长时间悬浮操作待验。保留单实例激活和连续联想候选定时的历史偶发记录。

空白包与预置 28 组、154 个虚构词汇的体验包 EXE 哈希一致，均已在不同的临时数据目录启动。打包器报告 tzdata 隐式导入警告，启动通过。空白包只有程序与运行依赖。原始参考和本轮渲染位于 Git 忽略目录，原有体验目录及真实数据保留。
