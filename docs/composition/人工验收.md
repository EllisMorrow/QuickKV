# QuickKV 组合输入 Windows 人工验收

从独立的「模拟体验」目录启动 QuickKV.exe，选择「组合输入」。体验时可先关闭占用同一全局热键的 QuickKV 实例。用下面的清单记录体验和实机行为。

1. **真实输入法与手感**。使用常用中文输入法，在普通文本、词元边界和浮窗查询框内组词。检查候选、确认、Esc、Tab、Enter、焦点，以及激活词元是否影响阅读。
2. **效率与可发现性**。先完成一份示例任务，再手打相同记录。比较耗时、误选、重新开面板次数和漏填。试一次从零找到模板、观察提示和备份入口。
3. **真实显示与鼠标**。在常用主题、两块屏幕和不同 DPI 下调整窗口、靠边打开浮窗。拖动词组及分类，悬浮展开第六组，确认鼠标路径、字体和裁切符合预期。
4. **真实外部应用**。在所用笔记或编辑软件中选择虚构的混合 Markdown，用已配置的回载快捷键采集。分别验证复制降级、新稿落字、目标变更和失败后草稿保留。外部应用可能自行转换换行，请单独记录。
5. **实际运行**。持续一段真实使用时间，记录卡顿、焦点丢失、内存或启动异常。若曾在旧版遇到单实例激活失败，可留意是否再现。

## 第一轮 UI 验收补充

重点复验独立浮窗跨窗口的鼠标移动与真实中文输入法，以及快速移动光标或拖选时曾出现的偶发字形异常。另试过一遍模块中心和模板中心的右键、排序及原光标插入，并核查观察维度「需补充」的位置。

## 第二轮人工体验

用真实输入法检查直接点击词元各段、拼音检索及跨窗模板编辑。连续尝试「词元 → 配置 → 词组 → 词条 → 关闭」，核对缩放光标偶发问题。跨不同 DPI 显示器移动主窗口，检查观察提示和预览、浮窗位置。确认词库别名同词多组时展示正确。

## 第三轮新增实机观察

在体验版用常用中文输入法检索并确认生词，检查候选主次、词片截断提示和 Enter 的选择手感。缩放主窗后在词元面板、配置窗口和非模态模板中心之间切换，留意实际鼠标光标恢复与窗口焦点。选择虚构 Markdown 从常用外部应用回载，检查独立回载模块和复制降级。自动覆盖的去重、词元自动附着、模式切换、归档草稿恢复无需重复做人工必测。


## 第四轮实机项目

- 在 VS Code 中选取虚构文本，分别通过唤出后的回载菜单和回载快捷键采集。检查成功建独立模块、切至第三方窗口时拒绝以及失败后手动复制。
- 使用常用字体和中文输入法，在窄窗口及不同 DPI 下检查字体回退、词片截断、组合词光标和候选菜单。
- 实测模块悬浮菜单的桥接和离开时序、快捷重命名和删除，以及深层分类的拖动手感。
- 记录真实录入中的误判、效率和焦点问题。留意单实例激活和连续联想候选定时的历史偶发记录。


## 第五轮实机验收

- 从所用编辑器把虚构混合大纲复制到剪贴板回载，点击候选并确认归属。另验证 VS Code 外部选区采集和复制降级。
- 使用真实输入法在已建立组合词前后输入逗号和文字、再删除和重新点击。测试中英文候选、字体替换和跨屏高 DPI。
- 在独立模块进行同词多组选择，验证全局搜索、三向关联和收藏，以及快捷模块右键。
- 保留单实例激活和连续联想候选定时的偶发记录。


## v2.0.0 第六轮实机重点

- 从实际应用唤出 QuickKV，分别在组合词、词组管理、片段及模块菜单打开时单击切换连续联想。检查真实鼠标悬浮和再次点击的节奏。
- 确认常用字体、大字号及多屏 DPI 中候选虚线清晰，组合方案及归属表内容可读。
- 在独立体验版中连续勾选、解除词组，尝试跨组切换和撤销。切换、关闭及退出片段中心，确认编辑内容按预期保存。
- VS Code 外部选区采集、真实输入法、外部回写复制降级和历史偶发仍需实机验证。


## 第七轮

第七轮实机重点为候选悬浮跨区与在真实中文输入法下的选区、三向入口在大字号及跨屏 DPI 下的表现、VS Code 自动选区采集与外部回写降级。使用虚构回载和片段数据，保留第六轮以来的历史偶发记录。

## 发布前预设验收

在全新目录启动。普通搜索输入「收到」，组合输入打开「日常速记」并点击示例前缀，测试片段插入和切换到空白模块。重新启动应保留用户对预设的编辑。用独立的旧数据副本验证升级不会补写预设。


## v2.0.1 发布候选人工验收

- 在实际使用的外部应用先定位光标，再呼出 QuickKV。分别通过普通搜索、连续联想和组合输入落字。对 VS Code、Notepad++ 和浏览器编辑器核对快捷键与接收效果。
- 使用虚构的中文、英文、多行 Markdown 和 Tab 缩进测试剪贴板落字。切走前台或关闭目标时核对降级复制，核对回载历史选区保持独立。
- 原生中文输入法、跨屏 DPI、不同字体大小、深浅主题及托盘重启仍需在常用设备上手验。用独立副本核对升级和恢复。
- 记录历史单实例激活与连续联想候选定时偶发问题。自动化某次通过不代表已定位根因。
