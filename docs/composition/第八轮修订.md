# 第八轮真实使用修订

本地验收版本为 v2.0.1。测试和体验数据均使用独立虚构内容。

| 条目 | 实际行为及验证 |
| --- | --- |
| R8-01 | 主词替换后保留主词面板及高亮。同组连续切换五次保留前后缀。已有跨组回归覆盖不兼容修饰清理、拒绝和撤销。 |
| R8-02 与管理词组入口 | 顶部「词组」及右上角「··· → 管理词组」复用全局管理。仅「词组」高亮。内容区 × 折叠内容，顶部 × 关闭浮窗。菜单事件测试验证空正文无新增词元。 |
| R8-03 至 R8-04 | 三向搜索统一「新建或查找」提示及完整悬浮文字。精确存在的词和组隐藏相应的新建操作，原候选继续可用。 |
| R8-05 | 新建主词组确认标明当前模块。前后缀确认标明实际主词。已绑定主词时，新建并关联空修饰词组只改变配置。 |
| R8-06 | 新修饰词使用全局双栏归组选择。按组名和组内词筛选，预览显示分类路径及命中词片。不可写入的特殊组及自身引用说明原因。直接使用无归属主词仍可先插入。通过实际模态窗事件验证模块外的深层词命中及选择，沿用专用词库与草稿事务。 |
| R8-07 | 主编辑器和复用组件的片段编辑器从实际字体计算四空格 Tab 宽度。新增与缩进优先使用子级、父级或邻近分支缩进依据。Qt 验证字体变化的实际 Tab 距离、多级新增、取消缩进、撤销及混合 CRLF/LF 无编辑回载。 |
| R8-08 至 R8-09 | 回载入口使用模块中心的过滤视图，以目录内稳定 ID 为准。更名保留来源，复制回载模块保留回载来源。排序只在过滤视图的槽位间调整。窗口测试覆盖已更名回载模块、名称含「回载」的普通模块、孤立草稿。 |
| 自动保存 | 移除手动入口。模块编辑与光标继续防抖保存，切换模块、模式、隐藏、关闭及既有退出、重启、备份和恢复入口提交待保存内容。保存失败时保留编辑态并定时重试。用拒写故障验证模式切换及关闭被拦截，随后保存正文、选区和光标。 |

## 验证记录

- 离屏全量复测 155 项通过。早先运行复现已有的单实例子进程退出后激活偶发失败，复跑通过，问题仍保留。
- Windows 原生 Qt 隐藏窗口执行组合输入专项 53 项，52 项通过。真实剪贴板那一项仅在离屏隔离剪贴板中执行。
- 单张 Windows 原生 Qt 渲染使用真实 Tab 文本和全局词组面板，保存于本轮本地测试包目录。两个 EXE 的隔离副本均验证加载 Windows Qt Widgets 并保持运行。
- 空白测试版预建空词库与空数据库，适用于空白模块验收。模拟体验版预置 28 个词组、154 个去重词、8 个模块，其中有 3 个正式回载模块。选择「项目管理」内已有结构的词元即可切换主词。修饰词归组可搜索「装订样本」内的词或其他模块词组。Tab 样例在「回载建立的模块 → 回载 · 层级检查」。

## 人工验收

- 用真实中文输入法测试预编辑、确认上屏、切换及退出。
- 在两块不同 DPI 屏幕上拖动，检查 Tab 显示、浮窗位置、键盘焦点与切换效率。
- 用常用外部编辑器验证真实 Tab/换行采集、回载与复制降级。
- 用旧版数据副本体验立即退出和托盘重启，重新启动后核对草稿、组合词和光标。测试包位于独立目录，无需覆盖日常安装。
