# QuickKV 组合输入交互规范

完整行为以[产品规格 V1.0](产品规格%20V1.0.md)为准。开发采用下表的九项通用交互验收。布局、触发条件和操作结果以产品规格为准。

| 图示 | 需验收的交互 |
| --- | --- |
| 1 整体界面 | 标题栏新增模式；模块、模板、回载、悬浮和高频操作保持紧凑；正文是可自由书写的大纲；按需预览、复制、落字。 |
| 2 三向交互 | 非激活时为普通文字；仅当前词元呈现前缀、主词、后缀三入口；选择即时更新；无值不输出连接符。 |
| 3 主词组语义 | 同组保留修饰词，跨组加载新规则；规则共享，实例独立；层级分类与组合排序分开。 |
| 4 组和时间 | 先显示五组，其余悬浮或点击立即展开；组和选项可排序；时间动态更新而选定值固化。 |
| 5 浮窗配置 | 左侧词组导航，右侧仅编辑当前组；已有组和词可检索引用；分类可递归；解除引用独立于删除词条。 |
| 6 模块和右键 | 模块下拉可检索且草稿独立；右键出现在鼠标附近，对普通文字、选区、词元、候选、分支提供上下文操作。 |
| 7 观察维度 | 轻量提示绑定分析父节点；四种状态按正文和用户判断更新；可直接补充对应位置。 |
| 8 同一编辑器回载 | 使用淡色提示区分候选和歧义；可临时使用和选择性归组；保护路径、代码和自然语言；原文字面保持。 |
| 9 安全保存 | 覆盖配置、词库、草稿及偏好；自动、手动、固定和保护快照有明确生命周期；验证跨文件恢复。 |

## 第一轮 UI 结构

独立词元浮窗在词元附近打开，在显示器工作区内定位。前主后选择共享紧凑词片，临时输入按需展开。模块中心集中输入工作空间的切换和管理，模板中心集中分支的预览、插入、保存和管理。观察面板显示四种状态，保留「需补充」的定位动作。见[第一轮 UI 修订](第一轮UI修订.md)。

第二轮采用词元实际字符范围直接打开相应方向，空查询显示主词组词片。Markdown 预览和模板中心均独立显示，模板插入使用当前有效正文光标。详见[第二轮 UI 修订](第二轮UI修订.md)。
