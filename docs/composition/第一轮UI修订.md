# QuickKV 组合输入第一轮 UI 修订

| 项目 | 处理结果与验收边界 |
| --- | --- |
| Q01 | 浮窗按词元屏幕坐标定位，统一宽度，同一锚点各页保留顶部位置和各自滚动记录。贴近任务栏时按最大可用区域调整 |
| Q02 | 前后缀用可换行词片，按文字取宽，保留选中、拖动与分类菜单 |
| Q03 | 临时输入改为组内加号，Esc 取消，Enter 消耗为当前实例的临时值。程序化点击验证词库未被写入 |
| Q04 | 空查询且组内候选较少时用词片，搜索和大量结果使用列表。保留原有匹配、方向键及 Enter |
| Q05 | 首五组的行高降低，独立浮窗使用显示器空间。虚构七组样例的前五组及「其他 2 组」在原生渲染中同屏可见；已有测试覆盖悬浮展开 |
| Q06 | 四个方向显示选中状态，实际选中的词片独立标识 |
| Q07 | 配置标题说明关联对象，区分「关联已有词组」和「引用词库词汇」，共享组名称提供提示 |
| Q08 | 左栏搜索组，右栏使用统一紧凑行高，保留分类下钻、返回与拖动。分类展开仍采用原有逐层浏览 |
| Q09 | 减少浮窗按钮边框，保留背景和选中反馈；中心突出主要操作，沿用 QuickKV 主题 |
| Q10 | 更多菜单分隔配置、输入、观察及数据，不重复提供模块中心 |
| Q11 | 静态确认组合编辑器位于旧整窗图形阴影效果下，组合模式禁用该合成层。自动测试和 Windows 原生隐藏窗口检查中，切换词元状态时光标位置及正文布局稳定。未能独立复现偶发字形变形，因果与真实 DPI 下的修复待验收 |
| Q12 | 独立浮窗采用统一宽度与按内容取高的策略，配置页更高。保留有效可见区域与内外滚动测试 |
| Q13 | 模块名称直接打开模块中心，包含搜索、切换、新建、右键及更多管理。名称和保护删除仍采用轻量确认 |
| Q14 | 模板中心整合搜索、范围、预览、原光标插入、保存当前分支、编辑和管理。实际入口验证搜索及预览、插入和一次撤销 |
| Q15 | 模块中心说明独立工作空间，模板中心说明可重复插入的分支；数据模型保持独立 |
| Q16 | 浮窗为所属主窗的 Qt 工具窗，按显示器工作区限制，可超出主窗口。测试覆盖小窗、换页和主窗隐藏；真实跨屏拖动待验收 |
| Q17 | 状态改为「需补充」和「状态」，保留联动与底层四态。关键名称、中心列表、候选与长词片提供全文提示；极端字号及其他动态菜单的截断仍需抽查 |
| Q18 | 模块及模板中心共用列表、菜单及布局形态；前主后使用统一词片。与参考图结构对齐，沿用原生窗口装饰和现有功能命名 |

## 实际视觉对照

使用 Windows Qt 和虚构体验数据渲染正文、三向选择、词组配置、模块中心、模板中心与观察面板。确认紧凑前缀列能同时显示第五组和展开入口。首次观察到配置列表行过高，后续统一了列表行高和选中背景。模块和模板中心保留原生窗口装饰及右键入口，管理按钮集中在「···」。观察状态沿用原「无法判断」名称。

真实中文输入法的候选位置、鼠标跨窗桥接、跨屏 DPI、偶发字形、录入手感及外部应用落字继续人工复验。外部回写方式保持安全复制。
