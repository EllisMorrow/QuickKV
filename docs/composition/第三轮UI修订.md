# QuickKV 组合输入第三轮统一修订

| 文字规范 | 实现及验证 |
| --- | --- |
| 一、九 · 统一与视觉层次 | 延续 QuickKV 主题。候选本体和来源分别绘制，来源较小、低对比。词组及组内词片复用可换行布局，侧栏标题和分类入口显示当前上下文，可能被截断的组名、候选及词片可悬浮查看。 |
| 二 · 检索与选择 | 空查询展示模块可用词组。顶部范围按钮打开可搜索的词片选择器，自定义词组可右键移出当前模块范围。统一候选使用来源前缀，复杂词条保留原文预览及插入路径，多组同名词须确认所属组。没有完全匹配时默认选中直接输入值，方向键仍可选择其他结果。 |
| 三 · 三向入口 | 正文点击词元各段直达对应页。无关联时可点击「配置关联词组」直接进入配置。 |
| 四 · 配置页 | 配置标题显示作用范围。右侧词条与分类使用可拖动、可右键操作的词片，点击分类进入其内容，顶部可返回上级。关联已有词组支持搜索及跨过滤条件多选。 |
| 五 · Markdown | 独立只读工具窗默认源码，可切换渲染。渲染视图收紧列表块上下间距，保留 Markdown 层级。 |
| 六 · 模块、模板、回载 | 模块中心入口无下拉箭头，范围可搜索、多选。非模态模板中心保留空白及分支新建、直接编辑、当前光标插入。新回载独立建模块，继承来源模块的词组范围，名称格式为「回载 · 日期-序号」。可靠候选自动附上词元结构，歧义保留待选，未知原文保留。 |
| 七 · 备份 | 手动备份包含草稿、模块、词组、关联、模板、观察设置和组合输入专用 Markdown 词库。自动备份是否包含草稿沿用现有偏好。可恢复配置与专用词库，或同时恢复备份中对应模块的归档草稿。恢复前写入保护快照。外部词库仅保留引用信息。 |
| 八、十 · 模式与光标 | 连续联想第一次单击进入，第二次单击返回普通搜索。边缘缩放中失去鼠标抓取、隐藏或失焦时清除缩放状态。保留标题按钮边缘点击及浮窗布局回归。 |

## 数据规则

直接输入确认后，在原光标位置插入词元，并将新值写入组合输入专用词库。修饰词组的「＋」确认后同时更新组及专用词库。更新前校验当前编辑范围，保持已有的跨文件事务保护。相同 Markdown 词条复用，取消及识别本身不写词库。恢复备份时，旧版独立回载草稿仍可作为归档副本载入。新回载写入模块、草稿与选中状态时使用同一次 SQLite 事务。

## 验证

- 全量自动化用例 124 项通过。原有 122 项的有效覆盖保留，因确认用词和自动回载规则变化而更新相应断言。新增用例覆盖单击切换、检索取消、确认用词、词条去重，以及可靠、歧义、未知混合回载。
- 一次打包并行期间，原有连续联想候选定时断言失败。随后串行全量通过，尚未确认间歇触发条件。此前单实例激活偶发失败记录仍有效。
- 真实中文输入法、多显示器 DPI、鼠标拖动手感及外部应用采集与回写见 [Windows 人工验收](人工验收.md)。

用虚构数据检查了 Windows Qt 隐藏窗口下的主词词片、候选来源及配置截图。源代码预览开窗默认状态和来回切换纳入自动回归。此前迭代目录仍在，交付入口为「第三轮最终测试」及「第三轮最终体验」。

最终版本追加 Windows 原生 Qt 隐藏窗口 4 项场景，均通过。两种测试包的 EXE 哈希一致，分别复制到临时隔离目录完成启动检查。空白包只有程序与运行依赖，体验包含 26 组和 152 个虚构词汇。PyInstaller 报 tzdata 隐式导入警告，两种包均通过启动检查。
