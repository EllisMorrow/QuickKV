# QuickKV 组合输入主动审计

## 发现和修复

| 严重程度 | 发现 | 修复及证据 |
| --- | --- | --- |
| 高 | 在有子节点的标题末尾按 Enter 会把原子节点挂给新建同级 | 光标位于标题末尾时，在整个分支之后新增同级。QTest 经正文按键验证，撤销还原原文 |
| 高 | 将末尾分支向上移动会多留一个换行，且混合换行下会选错分隔符 | 移动末尾分支时一并转移原分隔符。固定随机种子检查 24 组混合换行、节点身份和撤销 |
| 高 | 哈希正确的备份仍可携带非法保留份数或损坏模板，恢复后会留下无法使用的配置 | 恢复前校验配置类型、保留份数、模板正文和观察框架。两个校验和有效的异常包均在改写现有词库前被拒绝 |
| 中 | 主词检索没有上下键导航，确定主词后关闭全部入口 | 输入框上下键改变候选，按 Enter 确定后保留紧凑的三向入口。QTest 验证 Ctrl+J、方向键、Enter 和鼠标点击前缀。进入第一个修饰面板少一次重新激活，不增加确认次数 |
| 中 | 长词元可以挤压三向按钮和关闭入口。浮窗快捷键也会抢先处理查询框的 Esc | 标题按钮均分可用宽度，长文字省略，保留完整提示。跟踪浮窗输入法预编辑，在预编辑期间把 Esc 留给输入法 |

## 审查和验证边界

- 按去敏化规格、九项交互规范及已有 20 节追踪复核模式、编辑、词组、回载、模板、观察、持久化和动作入口。本轮实证覆盖重点变更路径，原追踪中尚未确认的项目继续保留。
- 以独立博物馆编目场景完成模块、回载、词元建立、共享组重命名、保存和备份恢复组合验证。原始 CRLF、词元快照和当前草稿保留。
- 用临时数据执行 20 轮窗口、模式、模块和浮窗切换，检查浮窗输入控件回收、时间刷新计时器及草稿隔离。此结果覆盖有限次生命周期，并未测量持续数小时的进程内存。
- Windows Qt 原生后端在隐藏窗口检查浅色、深色、465×275、18 像素字号和 170 字符以上词元。三向标题、配置及关闭入口位于浮窗内。交互测试使用合成事件，未操作真实桌面。
- 原有回写仍为安全复制。可靠的外部原选区替换能力、真实中文输入法、多显示器拖放、真实录入效率仍待人工验收。磁盘实际耗尽、长时间 soak 和任意第三方扩展 Markdown 没有获得本轮实机证据。保留原单实例激活偶发记录。

## 最终复测

全量 109 项通过。本轮新增 6 项有针对性的回归。PyInstaller 重新构建独立测试包，隔离副本生成通用默认词库并保持运行。打包目录检查未发现用户词库、数据库、备份、私人资料和原图。打包时仍有可选 tzdata 的隐藏导入提示。旧本地测试包保留。

## 浮窗和模拟体验补充

修复默认候选尺寸提示放大空面板，以及页面重建期间读取陈旧布局尺寸导致内容收缩的问题。重新测量发生于布局更新后，候选列表按有效行数占用空间，超出时由列表滚动。配置页优先获得更大空间，在光标上下空间不足时可使用整个工作区的可用区域。QTest 检查空、少量、大量候选的回转，三向与配置切换，以及 465×275 到 780×545 的真实控件可见区域与滚动范围。

第一轮 UI 修复将词元浮窗改为所属窗口的独立 Qt 工具窗，并按显示器工作区定位。相关变更和原生渲染检查见[第一轮 UI 修订](第一轮UI修订.md)。
