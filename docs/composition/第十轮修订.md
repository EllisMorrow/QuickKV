## Windows 原生派发证据

在隔离 Win32 EDIT 控件中，旧 SendKeys 试验返回成功但正文为空。改用共用派发的 SendInput 后，真实控件收到虚构中英文「QKV10 中文」。原生试验复用生产版的进程、前台、剪贴板序列守卫及 Unicode 派发，使用内联虚构测试输入，避免写入正在使用的系统剪贴板。该试验覆盖实际逐字接收。多行、Tab、Markdown 的剪贴板路径由自动化覆盖，真实第三方编辑器剪贴板接收、中文输入法和跨屏 DPI 仍待人工验收。

历史单实例激活及连续联想候选定时偶发问题继续跟踪。参见 [实际操作清单](人工验收.md)。

## 专项隐私审计与拟提交范围

- 核对 88 个现有 Git 文件及拟新增文件，暂存区为空。路径与内容扫描覆盖用户数据目录、数据库、配置、备份、日志、已知私人术语、本机用户路径、凭据标记及 PNG 元数据。扫描没有匹配。预置与截图使用独立虚构数据。
- ZIP 全量解压校验通过，共 1965 项。检查 565 个冻结模块，含预置资源代码，排除了体验生成工具、测试模块、旧动态目标模块、SQLite、正式运行词库、配置、草稿和备份。正式候选首次启动才生成专用词库。版号文件和产品版本均为 2.0.1。
- 从候选压缩包对应的构建目录复制至隔离路径后实际启动 EXE，验证已创建 8 个模块、29 个组、216 条词条、14 个片段及完成标记。独立空白测试版实际启动后保持空词库，未生成预置数据库。
- 拟提交范围为程序源码、测试、虚构体验生成工具及公开文档，涵盖第八至第十轮仍未提交的合并工作。候选 ZIP、独立空白测试版、发布说明草稿及截图存于忽略的 dist 目录。
- 既有主分支及版本标签历史未发现上轮已移除的七条路径。更早发布时记录的 GitHub 只读 PR 引用及外部副本不在本次清理范围。本轮保留旧构建、旧资料和本地真实数据。
