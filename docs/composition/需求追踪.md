## 阶段记录

- **0.1** 在项目虚拟环境完成原生 Qt 与无损数据原型。消除了 Qt 内部换行归一化、词元格式继承和块 ID 继承带来的歧义。独立临时目录测试在写词库前后结束子进程，区分回滚、前滚与第三方版本。
- **1** 在既有 QuickKV 弹窗接入组合输入和独立本地草稿。原生 Qt 提供光标与输入，应用统一撤销同时保存正文、词元、节点身份、原始换行和选区。
- **2** 词组配置、分类、三向选择、拖动排序、数值、动态时间、模块和专用词库已接入。复用连续联想匹配器和 Windows 文件替换接口，测试跨组行为、时间固化与并发替换恢复。
- **3** 回载、模板、观察、判断标准和备份已接入。回载始终要求目标重新核对选区后由用户粘贴。真实目标应用适配仍属阶段 4 的验收范围。
- **4** 自动回归、Windows Qt 视觉检查、隔离打包启动、隐私和性能检查见交付记录。真实 Windows 输入法、混合 DPI、系统选区、拖动和录入效率仍待人工验收。原始基线的单实例 Qt 激活用例曾偶发失败，单独和全量复跑通过，原因未定位。
