## 验收边界

- 正文候选下划线、候选三栏、词组勾选、模块批量和片段直接编辑均以虚构数据完成 Windows Qt 隐藏窗口渲染。
- 片段、回载及模块的原生程序化事件与真实鼠标、输入法、多屏 DPI 和外部编辑器不是同一类证据。需要单独验证 VS Code 采集、外部回写和真实系统唤出场景。
- 保留单实例激活和连续联想候选定时的历史偶发记录。本轮首次全量测试再次出现单实例子进程立即退出时激活信号未送达，后续全量复跑通过，根因仍待单独定位。
- 原始参考和原生渲染保存在本地忽略目录。空白与体验包互相隔离。没有发版、提交、推送或标记。

## 交付检查

- 最终源码全量 142 项通过，其中新增的专项回归覆盖同名候选忽略与选区恢复、跨组绑定、模式首次点击和片段保存失败。另有 16 项 Windows Qt 隐藏窗口测试通过。
