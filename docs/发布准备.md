# QuickKV v2.0.1 发布准备

本页记录 v2.0.1 的发布准备。README 介绍三种模式，CHANGELOG 记录用户可见变化。

## 交付物用途

- 正式发布候选压缩包从干净的 PyInstaller 目录生成，包含 Windows EXE 和运行库。首次启动生成内置通用资料。
- 空白测试版预建空 Markdown 词库，跳过首次初始化。适合验证从零配置。
- 模拟体验版用于测试复杂业务路径。本轮正式候选不带模拟资料，之前的模拟体验包继续保留。

## 首次使用与升级

参见 [预置资源清单](预置资源.md) 和 [README](../README.md)。已有安装使用旧资料。全新目录使用独立的首次初始化事务，目录中已有用户配置、词库或数据库时保留原资料。

## 发布前核对

- 核对版本、文档、Release 说明和压缩包 SHA-256。
- 阅读 [第十轮实现、隐私审计及验证结果](composition/第十轮修订.md)。
- 确认 [真实设备剩余验收](composition/人工验收.md) 中与实际使用有关的项。
- 提交、推送、标签和 GitHub Release 需用户验收后另行授权。
