# QuickKV v2.0.0 发布准备

本地待验收。用户说明集中在 README 的「快速开始」「连续联想」和「组合输入」，用户可见变更整理在 CHANGELOG 的 v2.0.0 节。工程记录和人工验收分别维护在组合输入文档目录。

## 首次启动

全新目录首次启动会生成 18 条普通词条，以及「日常速记」和「空白模块」两个组合输入模块。「日常速记」含两条已建立结构的组合词和待办、会议两个片段。预设无全局快捷码，内容可在软件内编辑。已有配置、词库或组合输入数据库时跳过预设写入。

## 发布前核对

- 用独立副本体验全新启动、常用词条搜索、组合词点击和片段插入。用旧版数据副本验证升级保留。
- 按组合输入人工验收清单检查中文输入法、跨屏 DPI、外部选区采集与复制降级。保留已知偶发记录。
- 通过专项隐私审查后才准备拟提交文件。发布包从干净构建目录产出，排除首次启动生成的词库、用户配置、草稿、数据库、备份和私有材料。
- 核对版本、更新说明和 Windows 包哈希。Git 提交、推送、标签及 Release 由后续明确授权执行。

## 本地验证

验收包位于 dist/QuickKV-v2.0.0-发布前验收。EXE 文件版本和产品版本均为 2.0.0。149 项自动化测试通过。使用该 EXE 的临时副本验证首次启动生成词库、结构化组合词和片段，Windows Qt 隐藏窗口验证可直接使用示例。
