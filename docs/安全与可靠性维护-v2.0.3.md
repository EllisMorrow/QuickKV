# QuickKV v2.0.3 安全与可靠性维护

本轮核对专项维护计划、独立报告摘要和测试分类，并在本地源码上确认修订范围。两份原始报告留在用户目录。

| 编号 | 核实与修复 |
| --- | --- |
| V-01 | 原文曾进入模板编译。现在字面量在引擎外拼接，过滤器参数、表单和剪贴板作为数据传递。引擎只装载输出相关语法与白名单过滤器。只有模板确实引用剪贴板时才读取。 |
| V-02 | 同一边界隔离未授权控制结构。解析采用顺序查找，重复合法表达式只编译一次。动态展开最多 16 MiB，每条词条最多 4096 个动态表达式，每个表达式最多 64 Ki 个字符。纯文字及混合模板中的字面量不计入动态输出限额。 |
| L-02 | 保留既有 INI 插值格式，保存受管理的字面字符串及 JSON 时一致转义百分号。无法按旧插值格式解析的字段尝试读取原值。旧版转写做法继续兼容，无全文件迁移。 |
| T-01 | 通过 Qt 事件循环等待可见面包屑出现，超时两秒。保留原有层级、禁用状态和点击跳转断言。 |

合法模板对照覆盖日期格式、表单字段复用、默认值、大小写、去空格、百分号、反斜杠和多行正文。实际 Markdown 词条入口覆盖先展开后转写与错误取消。配置测试覆盖百分号路径、连续百分号、旧格式、未知字段及原有失败回滚。剪贴板记忆的数据保存方式和说明继续沿用。L-03、L-04 未纳入产品改动。

Liquid 从本机可用的 2.1.0 更新到 2.3.1。采用 2.x 内已修复上游已知解析及加载器问题的版本。验收依赖安装于独立目录。本轮没有在用户运行目录更换依赖或修改配置。相关公告见 [Python Liquid 安全公告](https://github.com/jg-rp/liquid/security/advisories)。

## 验收结果

- 基线采用远端 main 的 1417bfc。v2.0.2 正式标签指向 1a248d7，两者差异为 README。修复前 161 项执行，160 通过，单实例激活偶发失败一次，跳过 0。
- 修复后 171 项全部通过。新增 9 项模板安全与兼容回归和 1 项配置回归。Windows 原生 Qt 组合输入专项 54 通过、1 跳过。该项需要隔离剪贴板，已在离屏全量中通过。面包屑专项额外重复 10 次通过。
- 5 组合法模板与旧实现对照一致。代表性双表达式预备及输出的百次小样分别约 0.019 秒和 0.013 秒，结果限于本机小样。旧行为中含反斜杠的可用参数保留原输出。以前无效的内嵌双引号现在可作为参数内容。
- 2.0.3 正式候选和空白测试版均实际从隔离目录启动。正式候选生成预置资源，空白版保持空白。检查 EXE 文件及产品版本为 2.0.3，并从冻结归档确认 Liquid 2.3.1。
- 保留单实例激活及连续联想候选的既有偶发记录。第三方窗口落字、真实输入法及跨屏 DPI 未在本轮实机验证。

## 发布和隐私

- 审核 11 个拟提交路径和空暂存区。候选 ZIP 全量检验 1973 个条目。检查未带入真实词库、配置、数据库、备份、日志和专项测试文件。两份独立原始报告仍留在本机。
- 拟提交范围为 README、CHANGELOG、维护记录、版本入口、Liquid 版本约束、模板渲染、配置读写、模板输出入口和相应回归测试。
- 正式候选 ZIP、空白测试版、SHA256SUMS 和 Release 说明位于独立本地候选目录。旧包和已有用户数据保留。
- 正式下载及校验值见 [v2.0.3 Release](https://github.com/EllisMorrow/QuickKV/releases/tag/v2.0.3)。
