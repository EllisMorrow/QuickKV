**把常用文本存进 Markdown 词库，需要时搜索、选择并插入。** QuickKV 是面向中文输入的 Windows 开源文本拓展工具：支持拼音首字母、多关键词搜索和多个词库，也可以保存回复、代码片段、模板等内容。

## 快速开始

1. 从 [Releases](https://github.com/EllisMorrow/QuickKV/releases/latest) 下载并解压 Windows 程序，启动 QuickKV，阅读并确认启动声明。
2. 在需要输入文字的地方按 `Ctrl + Space`，输入关键词或拼音首字母搜索。
3. 使用方向键选择并按 `Enter`，或用鼠标单击词条，将内容插入当前应用。
4. 在系统托盘右键管理词库和设置；也可以编辑程序目录下自动创建的 `MD词库-需自动载入的请放入/词库.md`，添加自己的常用内容。

> 剪贴板记忆默认关闭。开启后，复制的文本会以明文保存在本机词库中；请避免复制不希望被记录的敏感信息。快捷码默认开启，会监听按键以匹配触发码；可在托盘关闭。详见[重要声明与许可协议](#privacy-and-license)。

## 功能概览

- **搜索即用**：用中文、拼音首字母或空格分隔的多个关键词查找词条；收藏和最近使用可帮助常用结果靠前。
- **本地 Markdown 词库**：同时使用多个词库文件或文件夹，管理常用回复、代码片段和多行模板。
- **连续联想**：在多行草稿中边写边查找、插入词条，再将整段内容输出到目标应用。
- **快捷码与动态模板**：直接输入快捷码触发词条，也可以在模板中填写日期、剪贴板内容和临时输入字段。
- **按需调整输出**：支持输出转写规则、三种粘贴方式，以及可选的剪贴板文字记忆。

## QuickKV 核心特性

*   **全局热键**: 在任何地方按下 `Ctrl + Space` 即可呼出搜索框。默认热键通过 Windows 原生 API 注册；快捷码默认开启，确认启动声明后生效，可在托盘关闭。连续字符串盲打触发默认关闭。
*   **多词库管理**:
    *   支持同时加载多个 `.md` 词库文件。
    *   支持手动添加单个 `.md` 文件，也支持直接添加一个词库文件夹并自动加载该文件夹当前层级下的 `.md` 文件。
    *   可在托盘菜单中动态添加、启用/禁用、移除词库。
    *   可快速打开词库文件所在的目录，方便编辑。
    *   右键“添加到词库”会按所在目录分组并显示词库文件名；悬停可查看完整路径，便于区分同名词库。
*   **剪贴板记忆**:
    *   默认关闭；仅在您主动开启后才会自动记录剪贴板文本。
    *   历史记录以明文保存在本机的 `MD词库-需自动载入的请放入/剪贴板词库-勿删.md`，请勿在启用期间复制不希望保留的敏感文本。
    *   在搜索框为空时优先显示剪贴板历史，方便快速粘贴。
    *   支持自定义记忆数量和一键清空历史。
    *   支持**定时清除**：开启后剪贴板记录将在设定的分钟数后自动清除，减少隐私残留风险。
*   **词条管理**:
    *   支持在程序内通过右键菜单直接**添加、编辑、删除**词条。
    *   支持多行词条（父子内容），用于管理复杂的模板和代码片段。
    *   独有的 ` ``不出现`` ` 语法，可在粘贴时忽略父级标题。
    *   **快捷码** ` ``k:xxx`` ` / ` ``K：xxx`` ` 语法都可用，通过输入 `xxx` 直接触发粘贴，实现零点击操作。
    *   **别名** ` ``bm:别名1、别名2`` ` / ` ``BM：别名1、别名2`` ` 语法都可用，可让同一条词条拥有多个搜索入口，但实际展示和输出仍保持主词条内容不变。
    *   **中文模板变量** `{{今天}}`、`{{剪贴板}}`、`{{输入:项目名}}` 等语法，可让一条词条在输出时自动带上日期、剪贴板或临时填写的字段。
*   **智能搜索**:
    *   支持对父级词条进行关键词模糊搜索和多关键词筛选（空格分隔）。
    *   支持**拼音首字母搜索**，输入 `qd` 即可匹配“请定”。
    *   支持**收藏置顶 + 最近使用微调**：常用词条可以在相近结果中更靠前，但不会粗暴打乱原本的匹配相关性。
*   **软件粘贴方式**:
    *   保留 `Ctrl+V`、`Ctrl+Shift+V`、`输入模式` 三种全局手动方式，方便针对不同软件自行选择更稳的方案。
    *   默认仍推荐 `Ctrl+V`，保持主链尽量简单、稳定、可预期。
*   **高度自定义**:
    *   支持**日间/夜间**双主题。
    *   可自由**调整窗口大小**和**设置字体大小**。
    *   支持**窗口置顶**（图钉功能）。
*   **稳定性保障**:
    *   **原生快捷键**: 使用 Windows 原生 API 注册全局热键，减少对键盘钩子的依赖；若快捷键被占用，注册仍可能失败。
    *   可选的**间隔时间自动重启**功能，可按需定时重启程序。
*   **轻量与高效**: 后台运行，并监控词库文件变化以重新加载内容。

## 如何选择工具

QuickKV 聚焦通过搜索找到并输出常用文本；不同工具适合不同的工作习惯：

- **输入法自定义短语**：如果只有少量固定短语，输入法自带功能可能已经够用。QuickKV 提供列表式搜索和多个 Markdown 词库，适合需要管理较多内容的场景。
- **FastKeys、PhraseExpander**：提供更广泛的自动化或文本拓展能力。QuickKV 侧重中文词条的搜索和管理；需要其他能力时，也可以按需组合工具。
- **Ditto**：侧重剪贴板管理。可以关闭 QuickKV 的剪贴板记忆，用 Ditto 管理剪贴板、用 QuickKV 管理和搜索词库。
- **AutoHotkey、Espanso、Flow Launcher、Quicker**：各有脚本、插件或可定制工作流。QuickKV 已提供现成的文本搜索与拓展界面；如果需要更多自动化，也可以选择或搭配这些工具。

作者更喜欢用图形化方式管理大量程序快捷方式，例如使用 OneCommander 的分类文件夹。工具是否值得使用，取决于自己的实际需求和习惯。

## 用户手册

### 1. 安装与配置

**使用 Windows 发布包**

从 [Releases](https://github.com/EllisMorrow/QuickKV/releases) 下载并解压完整程序目录，运行其中的 `QuickKV.exe`，无需安装 Python。首次启动后，程序会在 EXE 同级目录创建 `用户数据/` 和 `MD词库-需自动载入的请放入/`，并生成示例词库。请保留整个程序目录，并定期备份自己的词库和用户数据。

**从源码运行（Windows）**

在项目根目录创建并激活虚拟环境，再安装依赖并启动实际入口：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python src/main.py
```

源码运行时，默认词库和用户数据创建在 `src/` 下。项目依赖和 Qt 版本会影响 Python 兼容性，请使用与当前依赖兼容的 Python 版本；程序的全局热键等功能依赖 Windows。

**编辑词库**

用任何文本编辑器打开 `.md` 词库文件。程序支持两种格式的词条：

**1. 单行词条**
每一行以 `- ` (减号 + 空格) 开头即可。
```markdown
- 我的个人邮箱是 my-email@example.com
- 公司地址：XX省XX市XX区XX路XX号
```

**2. 多行词条 (父子内容)**
以 `- ` 开头的行作为“父级”（用于搜索），其下方所有不以 `- ` 开头的行都会被视为“子内容”。

```markdown
- 这是一个父级
这是它的子内容第一行
  这也是子内容（支持缩进和空行）

- 这是一个模板标题 ``不出现``
  这是模板的第一行内容
  这是模板的第二行内容
```

*   **` ``不出现`` ` 语法**: 如果您希望在粘贴时只输出子内容，而忽略父级（例如模板的标题），只需在父级行末尾加上 ` ``不出现`` ` 即可。

**3. 快捷码 (高级功能)**
快捷码是一种无需呼出搜索框即可快速粘贴内容的方式。

*   **设置快捷码**: 在词条的父级行末尾，添加 ` ``k:触发码`` ` 语法即可。`k` 或 `K` 都支持，英文冒号 `:` 和中文冒号 `：` 也都支持。触发码可使用字母、数字及可识别的符号组合。
    ```markdown
    - 我的个人邮箱 ``k:mymail``
    - 项目路径 ``K：p1;``
    ```
*   **使用快捷码**:
    1.  在系统托盘菜单中确认“开启快捷码”已勾选。
    2.  在任何文本编辑器中，直接输入您设置的触发码（例如 `mymail` 或 `p1;`）。
    3.  程序会自动删除您输入的触发码，并将其替换为对应的词条内容。

**4. 别名 (Alias)**
如果一条词条本身写得比较长，或者你平时会用不同叫法去记它，可以给这条词加上“别名”。这样你搜索别名时，仍然能找到原来的主词条。

*   **设置别名**: 在词条父级行的末尾，加上 ` ``bm:别名1、别名2，别名3`` `。`bm` 或 `BM` 都支持，英文冒号 `:` 和中文冒号 `：` 也都支持。分隔符只需要用中文的 `、` 或 `，`。
    ```markdown
    - 这是一行文字 ``bm:wz1、文字模板，常用文案``
    - 项目日报模板 ``BM：ribaomoban、日报，rb``
    ```
*   **使用方式**:
    1.  正常打开 QuickKV 搜索框。
    2.  输入主词条内容，能搜到它。
    3.  输入你设置的别名，也同样能搜到它。
*   **它的工作方式很简单**:
    *   别名只负责“帮你搜到这条内容”。
    *   搜索结果里显示的，仍然是主词条本身。
    *   真正复制或粘贴出去的，也仍然是主词条内容，不会把 `bm:...` 这一段带出去。
*   **兼容性说明**:
    *   别名可以和 ` ``不出现`` `、` ``k:xxx`` ` 一起写在同一行里使用。
    *   如果一个词条有多个别名，程序会自动去掉重复项和多余空格。
    *   旧的 ` ``BM::...`` ` 双冒号写法现在不再作为正式写法，推荐统一改成单个冒号。

**5. 收藏与排序增强**
如果你有一些特别常用的词条，不想每次都重新翻找，可以直接在搜索结果里把它收藏起来。这样 QuickKV 以后会更懂你的使用习惯，但又不会把原来的搜索逻辑搞乱。

*   **怎么收藏**:
    1.  在 QuickKV 搜索结果里，找到你常用的那条词。
    2.  用鼠标右键点击它。
    3.  选择 `收藏`。
*   **收藏后会发生什么**:
    *   这条词以后在搜索时，会在“本来就差不多相关”的结果里更靠前一点。
    *   它不会无脑压过明显更相关的结果，所以整体搜索逻辑还是以原本的匹配相关性为主。
    *   如果你开启了“词条-归属显示”，收藏项的归属徽章前会出现一个 `⭐`。
*   **最近使用也会参与微调**:
    *   你经常真正选中并输出的词条，在相近结果里也会更顺手地往前一点。
    *   只是浏览、悬停、来回移动焦点，不会被当成“最近使用”。

### 转写功能

托盘菜单中，“自动载入的md词库”下方的“转写功能”可设置最终输出替换规则。每行一条，左右均使用英文双引号：

```text
# 标点和词组转换
"，" => ","
"您好" => "你好"
# 删除指定内容
"不需要的字符" => ""
# 将字面标记转为换行
"[换行]" => "\n"
```

支持 JSON 字符串转义（`\n`、`\t`、`\"`、`\\`）；空行和以 `#` 开头的整行注释忽略。识别内容不可为空或重复。按原文从左到右匹配、区分大小写，同位置长词优先，替换结果不再次匹配，不使用正则表达式。

窗口提供实时预览、错误行提示与启用开关。点击“应用”成功保存后立即生效，无需重启；删除规则后应用即失效，清空规则后应用即取消全部转写。关闭未应用的窗口时可选择保存或放弃。保存失败会保留原来的有效设置。

转写在模板展开后执行，覆盖搜索选词、快捷码及剪贴板历史条目的输出；不会改写 Markdown 词库、搜索内容或历史记录原文。设置窗口的测试文本不会写入剪贴板或发送。

**6. 中文模板变量**
如果你希望一条词不是每次都输出完全一样的内容，而是能自动带上当天日期、当前剪贴板内容，或者在输出前临时让你填几个字段，就可以用中文模板变量。

*   **最常用的写法**:
    ```markdown
    - 今天日期：{{今天}}
    - 当前时间：{{现在}}
    - 贴上剪贴板：{{剪贴板}}
    - 项目名称：{{输入:项目名}}
    - 联系人：{{输入:姓名|默认:张三}}
    - 会议日期：{{今天|格式化:%Y-%m-%d}}
    - 备注：{{剪贴板|默认:当前剪贴板没有文字}}
    - 客户姓名：{{输入:姓名|去空格}}
    ```
*   **这些写法分别是什么意思**:
    *   `{{今天}}` 会输出当天日期。
    *   `{{现在}}` 会输出当前日期和时间。
    *   `{{剪贴板}}` 会把你当前复制的文字带进去。
    *   `{{输入:项目名}}` 会在输出前先问你一次“项目名是什么”。
    *   `{{输入:姓名|默认:张三}}` 会弹出输入框，但默认先帮你填好 `张三`。
*   **如果一条词里有多个输入字段**:
    *   QuickKV 会一次性弹出一个小表单统一让你填写，不会一个一个反复打断你。
    *   如果同一个字段写了两次，例如两个地方都用了 `{{输入:项目名}}`，程序只会问你一次。
*   **几个容易记住的小规则**:
    *   `格式化` 只适合用于 `{{今天}}` 和 `{{现在}}`。
    *   `默认` 适合给 `输入:` 或 `剪贴板` 这类可能为空的内容兜底。
    *   如果模板写错了，程序会直接提示你哪里有问题，并取消这次输出，不会把半成品发出去。
*   **它适合用来做什么**:
    *   日报、周报、工单备注、客服回复、项目记录、联系信息等需要“固定结构 + 少量动态内容”的词条。
    *   比如一条模板写一次，以后每次用时只补上项目名、姓名、日期这些变化的部分就够了。

**7. 软件粘贴方式**
如果你发现某些软件里“能搜到，但不容易落字”，可以先从这里调整。QuickKV 现在保留三种全局手动粘贴方式，默认仍建议先用最稳定、最通用的 `Ctrl+V`。

*   **三种方式分别适合什么情况**:
    *   `Ctrl+V`：默认方式，适合大多数普通输入框、编辑器和日常软件。
    *   `Ctrl+Shift+V`：适合某些更偏纯文本粘贴的场景。
    *   `输入模式`：当普通粘贴不理想时，可以尝试让程序直接模拟输入文字。
*   **怎么切换**:
    1.  在系统托盘菜单里打开“软件粘贴方式”。
    2.  在 `Ctrl+V`、`Ctrl+Shift+V`、`输入模式` 三种方式里选择一种。
    3.  切换后直接重新测试当前软件即可。
*   **小提醒**:
    *   不同软件对粘贴方式的接受程度不一样，遇到问题时优先手动切换测试。
    *   如果目标软件是管理员权限运行，而 QuickKV 不是，同权限限制下仍可能无法落字，这属于 Windows 自身限制。

## 开发者指南

欢迎开发者参与 QuickKV 的改进和二次开发。以下是本项目的技术架构与开发指引：

### 1. 技术栈 (Tech Stack)

*   **核心语言**: Python；具体版本需与当前依赖兼容。系统交互功能面向 Windows。
*   **GUI 框架**: PySide6 (Qt for Python 6) - 用于构建无边框悬浮窗、托盘菜单和渲染优化的富文本引擎。
*   **全局系统交互**:
    *   `ctypes.windll.user32` - 极低底层的 Windows API 调用，用于全局热键 (RegisterHotKey) 注册；快捷键被占用时注册可能失败。
    *   `pynput` - 用于实现全局键盘钩子，在后台毫秒级监听连续字符串触发密码，以及实现底层按键拦截、回退补偿 (Auto-Erase)。
    *   `pyperclip` - 高稳定性的跨应用程序剪贴板读写库。
*   **文本检索与分词**:
    *   `pypinyin` - 提供高效精准的中文字符转首字母逻辑，实现无缝的首字母模糊搜索。
    *   `python-liquid` - 作为中文模板变量的底层渲染引擎，负责安全执行最终输出前的模板展开。
*   **文件系统监控**:
    *   `watchdog` - 监控词库文件与目录变化，触发重新加载。

### 2. 项目架构 (v1.2+ MVC 分解版本)

为了实现高解耦度与提升未来的维护性和 AI 辅助开发效率，QuickKV v1.2 将原本单文件的逻辑进行了彻底的物理隔离，拆分为以下核心模块：

*   **`core/` (核心配置与数据层)**: 存放了不包含UI组件的纯逻辑代码，包含配置加载 `config.py`，参数管理 `settings.py`，全盘词库聚合和搜索映射逻辑 `word_manager.py`、词源解析 `word_source.py`，以及收藏状态管理 `ranking_state.py` 与中文模板渲染 `template_renderer.py`。
*   **`ui/` (表现层)**: 存放所有基于 PySide6 构建的图形界面组件，如主要的搜索无边框窗口 `search_popup.py`，负责渲染多行变色排版的 `delegates.py`，以及其余弹框 `components.py`。
*   **`services/` (系统服务层)**: 集成了所有后台监听进程，负责与操作系统的外部交互。包括 Windows 原生快捷键调用 `hotkey_manager.py`，以及基于 `pynput` 捕获快捷码的 `shortcut_listener.py`。
*   **`main_controller.py`**: 协调界面、词库和系统服务，并处理输出、监听及资源生命周期。

### 3. 开发核心技术点

*   **连续字符串防冲突无痕盲打 (String Trigger)**: 使用输入缓冲区识别连续字符串；匹配后发送退格键删除触发符，再呼出窗口。该功能默认关闭。
*   **原生快捷键与线程安全**: 使用 `ctypes` 在一个独立的 `threading` 线程中监听热键。触发时，通过 PySide6 的**信号/槽机制**安全地通知主 GUI 线程执行 UI 操作，将界面操作交由 GUI 线程处理。
*   **超长列表极速渲染缓存**: 针对 `QTextDocument` 耗时的 HTML 生成流程，在 `delegates.py` 中挂载了 LRU 内存字典。将文本、窗口状态、甚至动态高亮特征码结合作为 Key，以减少滚动列表时的重复渲染。
*   **高鲁棒性防抖机制 (Debounce)**: 搜索框与文件系统监控（使用 `QTimer` 或 `watchdog`）分别使用 200ms 和 500ms 的防抖，减少输入或密集保存时重复处理。

### 4. 项目结构

```
.
├── src/                    # 项目源代码总目录
│   ├── main.py             # 极简入口启动脚本
│   ├── main_controller.py  # 核心总控与信号调度中枢
│   ├── core/               # 核心层 (配置、数据解析、状态)
│   ├── services/           # 后台系统交互服务 (热键、后台钩子)
│   ├── ui/                 # 图形界面层 (组件、无边框渲染、重绘)
│   └── utils/              # 通用工具模块 (路径转换)
├── README.md               # 项目说明文档
├── CHANGELOG.md            # 项目版本变更历史

└── requirements.txt        # 项目环境依赖清单
```
> **注**：`icon.png` 与 `icon.ico` 是仓库内的静态资源。源码运行时，配置、缓存和默认词库位于 `src/` 下；打包版运行时，这些用户文件位于 `QuickKV.exe` 旁的 `用户数据/` 与 `MD词库-需自动载入的请放入/`。请勿把个人配置、缓存或词库提交到仓库。

### 5. 构建可执行文件 (Windows)

本项目使用 PyInstaller 进行独立分发打包封装设计。建议在隔离的 Python 虚拟环境中执行，以保持输出包体精简。

1.  **安装 PyInstaller**:
    ```bash
    pip install pyinstaller
    ```

2.  **执行打包命令**:
    在项目根目录下使用项目的 spec 构建，并把 MIT 许可证放到发布目录根部：
    ```powershell
    $pythonBase = .\venv\Scripts\python.exe -c "import sys; print(sys.base_prefix)"
    $originalPath = $env:Path
    try {
        # 避免 PyInstaller 从其他应用的 PATH 目录收录同名 DLL。
        $env:Path = "$(Resolve-Path .\venv\Scripts);$pythonBase;$pythonBase\DLLs;$env:SystemRoot\System32;$env:SystemRoot"
        .\venv\Scripts\python.exe -m PyInstaller --noconfirm --clean QuickKV.spec
        if ($LASTEXITCODE -ne 0) { throw "QuickKV 打包失败" }
    } finally {
        $env:Path = $originalPath
    }
    Copy-Item LICENSE dist\QuickKV\LICENSE
    ```
    *   `QuickKV.spec` 统一管理无控制台模式、Windows EXE 图标和运行时托盘图标。
    *   发布 ZIP 必须包含根目录的 `LICENSE`。
    *   用户级产生的文件（日志、数据、词库）在运行时分离在外部生成。

3.  **获取结果**:
    构建成功后，绿色免安装程序位于 `dist/QuickKV/`；正式发布时将整个 `QuickKV/` 目录压缩为 ZIP。
